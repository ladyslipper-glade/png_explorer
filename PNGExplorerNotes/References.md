# Useful References

## Ada

- [Ada 2022 Reference Manual](https://arg.adaic.org/ada-reference-manual)
- [Ada Community](https://ada-lang.io/) website.
- [Alire](https://alire.ada.dev/), an Ada build tool and package manager.
