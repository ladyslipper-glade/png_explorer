This folder contains design notes for PNG Explorer. These notes are not intended to be user-facing documentation. They are instead a place where I can sketch out implementation ideas and describe implementation choices.

These notes are in Markdown, but I'm using the Obsidian note-taking app to edit them. Obsidian provides a number of UI conveniences and other features that I like. However, the notes can be edited in any text editor.

Non-Obsidian users can ignore the `.obsidian` folder where Obsidian keeps its configuration.

Note that, by default, Obsidian uses soft line breaks when formatting paragraphs. This means each paragraph is stored as a single long line. Configure your editor to do the same for maximum compatibility between editing tools.

As a final note: I don't anticipate any other contributors to this project, at least not for a while (if ever!), and so I'm referring to myself in the first person as an editorial convenience.

Thanks!
